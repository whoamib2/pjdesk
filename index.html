Built to stay yours

Every connection runs through the server you control. PJDesk has no cloud service behind it — nothing to sign up for, nothing watching.

Your server, your data

Computers find each other only through the PJDesk server you run, on a spare PC or a small VPS. No third party ever sees your screen or your traffic.

Works at the sign-in screen

Install the background service and reach a computer before anyone logs in — through the lock screen, the sign-in screen and UAC prompts, including Ctrl+Alt+Del.

End-to-end encrypted

The two computers talk over QUIC with TLS 1.3. Passwords are checked with SPAKE2, so they never travel the wire — not even the server can read them.

One ID, one password

Each computer gets a nine-digit ID and a one-time or permanent password. Sign in to your server to keep an address book of saved computers on every machine.

Fast and smooth

DXGI Desktop Duplication capture, OpenH264 video and credit-based flow control keep the picture sharp and the pointer responsive, direct or relayed.

Open source, MIT

Read every line, build it yourself, rename it, run it forever. No telemetry, no license server, no surprise. The whole thing is yours.

Running in three steps

One server for all your computers, then the app on each machine. That's the whole setup.

Run the server

Install PJDesk Server on any always-on computer or a VPS and start it as a service. It listens on one port for signaling and relay.

Install the app

Put PJDesk on each computer and point it at your server's address once. Every machine gets its own ID and password.

Connect

Type a computer's ID and password to control it, or sign in and pick it from your address book. Direct when it can, relayed when it must.
